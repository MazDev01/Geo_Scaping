# Geo Scraping — กวาดรายชื่อธุรกิจจาก Google Maps ทั่วประเทศไทย

ระบบกวาดข้อมูลธุรกิจ (ชื่อ, ประเภท, ที่อยู่, เบอร์โทร, อีเมล, เว็บไซต์, คะแนนรีวิว, พิกัด) จาก Google Maps
แยกตามจังหวัดและหัวข้อ ใช้ตัวกวาดโอเพนซอร์ส [gosom/google-maps-scraper](https://github.com/gosom/google-maps-scraper)
ควบคุมด้วยสคริปต์ Node.js ในโฟลเดอร์ `tools/`

> **ข้อมูลที่กวาดได้ไม่ได้อยู่ใน repo นี้** (มีเบอร์โทร/อีเมล — เก็บใน Google Drive โฟลเดอร์ DATA แบบส่วนตัว)
> repo นี้มีแค่โค้ด + ไฟล์สถานะความคืบหน้า เพื่อให้คนอื่นกวาดต่อได้

## ติดตั้ง (Windows)

1. ติดตั้ง **Node.js** (LTS) ที่ `C:\Program Files\nodejs\` จาก https://nodejs.org
2. ดาวน์โหลดตัวกวาด `google_maps_scraper-1.18.1-windows-amd64.exe` จาก
   https://github.com/gosom/google-maps-scraper/releases/tag/v1.18.1
   แล้ววางไว้ในโฟลเดอร์นี้ **เปลี่ยนชื่อเป็น `gmaps-scraper.exe`**
3. ติดตั้งไลบรารีสร้าง Excel:
   ```
   cd tools
   npm install
   ```
4. ถ้าจะกวาดต่อจาก **จังหวัดที่ค้างอยู่** ให้ขอไฟล์ `<จังหวัด>-raw.csv` และ `<จังหวัด>-scrape.log`
   ของจังหวัดนั้นจาก Google Drive มาวางในโฟลเดอร์ `จังหวัด/<NN ชื่อจังหวัด>/` (ไม่มีก็ได้ แต่จังหวัดนั้นจะเริ่มใหม่)

## ใช้งาน

| ไฟล์ | ทำอะไร |
|---|---|
| `resume-all.bat` | **เริ่ม/ทำต่อ** — ข้ามจังหวัดที่เสร็จแล้ว ทำต่อจากจุดที่ค้าง |
| `stop-all.bat` | หยุดทุกอย่างอย่างปลอดภัย (ข้อมูลไม่หาย) |
| `progress.bat` | ดูความคืบหน้า |

ผลลัพธ์ต่อจังหวัดอยู่ที่ `จังหวัด/<NN ชื่อจังหวัด>/`:
`<จังหวัด>-all.xlsx` (รวม) และ `<จังหวัด>-แยกตามหัวข้อ/` (17 หัวข้อ — สร้างเฉพาะหัวข้อที่มีข้อมูล)

### ข้อควรระวัง
- เปิดได้ **ทีละหน้าต่าง** — อย่ารัน `resume-all.bat` ซ้อน
- ห้ามปิดเครื่อง/Sleep ระหว่างกวาด (ใช้ `stop-all.bat` ก่อนปิดเครื่อง)
- เครื่อง RAM น้อย (4 GB) ใช้เบราว์เซอร์พร้อมกัน 2 ตัว (`CONCURRENCY` ใน `tools/run.js`) — เครื่อง RAM 8 GB+ ปรับเป็น 3–4 ได้
- เน็ตหลุด: คิวรอจนเน็ตกลับมาเอง; โดน Google บล็อก: พัก 60 นาทีแล้วลองใหม่

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `tools/provinces.js` | รายชื่อ 75 จังหวัด (ลำดับคิว), ย่านที่แตก, คำค้นต่อจังหวัด |
| `tools/queue.js` | วนทำทีละจังหวัด ข้ามที่เสร็จแล้ว เช็กเน็ตก่อนเริ่ม |
| `tools/run.js` | รันตัวกวาดจนครบทุกคำค้น (เริ่มต่อเองถ้าค้าง) แล้วสร้าง Excel |

| `tools/split.js` | แยก Excel ตาม 17 หัวข้อ |
| `tools/progress.js` | รายงานความคืบหน้า |
| `keywords-*.txt` | คำค้นของภูเก็ต/กรุงเทพ |
| `จังหวัด/*/keywords.txt`, `*-searched.txt`, `*-done.txt`, `*.resume.json` | สถานะความคืบหน้า (ไม่มีข้อมูลติดต่อ) |

แตกให้ครบทุกอำเภอสำหรับ 13 จังหวัดใหญ่ + กรุงเทพ (~2,300–2,600 คำค้น, ~2.5–4 วัน):
เชียงใหม่, ชลบุรี, สุราษฎร์ธานี, กระบี่, ประจวบคีรีขันธ์, พังงา, นนทบุรี, สมุทรปราการ, ปทุมธานี, ระยอง, สงขลา, เชียงราย, นครราชสีมา
- กรุงเทพ: แตก 50 เขตเพิ่มสำหรับหัวข้อ international school, daycare, wellness center, property management, villa management, summer camp + ลองใหม่ 9 คำที่ล้มเหลว
- ใช้ `-resume` กับไฟล์ raw เดิม → ข้ามร้านที่มีแล้ว
- โรงแรม: Google แสดงได้ 20 แห่ง/การค้น — ถ้าต้องการครบจริงต้องใช้โหมด grid (ทำทีหลังสุด)
